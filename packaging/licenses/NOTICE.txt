Tracks & Trails — third-party notices
=====================================

Tracks & Trails is licensed under the MIT License; see LICENSE at the root of the
distribution. This file records the third-party components distributed with it and
the obligations that attach to them.

Qt (via PySide6) — LGPLv3
    Qt-LGPLv3.txt, and Qt-GPLv3.txt which the LGPLv3 incorporates by reference.
    Qt is dynamically linked and replaceable: the Qt libraries ship as shared
    libraries alongside the executable rather than linked into it, so a recipient
    may substitute their own build of Qt. That is the binding constraint recorded
    in this project's LIC-001 decision, and packaging/artifact_gates.py checks it
    on every build rather than leaving it to be believed.

FFmpeg — LGPL-3.0-or-later  (Windows distributions only)
    ffmpeg-LGPL.txt. This whole directory is bundled as a unit, so that text also
    ships in Linux artifacts — where ffmpeg is a system dependency and is NOT
    distributed with this application (OPS-001). Read it as the licence of the
    Windows build; on Linux it covers nothing this artifact contains.
    The bundled Windows build is an LGPL build, never a GPL one, and it is shared
    rather than static so the libraries stay replaceable (LIC-001). Which build,
    its digest and its source are recorded in packaging/licenses/README.md and
    pinned in packaging/fetch_ffmpeg.py.

yt-dlp — Unlicense
    yt-dlp-Unlicense.txt. Public domain; no obligations attach.
