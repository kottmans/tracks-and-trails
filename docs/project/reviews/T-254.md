### Implementation and design judgments

Ruling 3 was implemented within its authority. It explicitly permitted the private-method
subclass if feasible, and the fresh session makes the boundary small and inspectable. There
was no need to return a buildable design to the maintainer for another ruling.

The child lookup session carries the proxy, source address and socket timeout; it deliberately
excludes site headers, cookie sources and client certificates. Those authentication inputs
belong to the content site, not SponsorBlock. The original postprocessor retains its retry
policy; the new session changes the transport carrying the request, not category selection or
the fixed destination. Sharing only the logger does not copy authentication. Inspected the
pinned upstream method and the literal-text drift test: an upstream change requires reassessment,
rather than silently updating a copied method. No broader session policy is needed for this fix.

The empty-choice check and download-only installation prevent lookups while off and during
probes. The category constants are checked against upstream, the two non-skippable categories
cannot be cut, each row has its own exclusive button group, and marked chapters are held in the
model and editor. Accessibility names include the category and action. The composed chain has
one chapter modification and one metadata writer; the real-file tests establish both tag
preservation and cuts. Combining hatch chapter removal/keyframe intent in that pass is necessary
to prevent the measured stale-chapter result, and is within this task.

**The two equivalent mutations are correctly judged.** `Preset` and `DownloadRequest` each
convert both SponsorBlock sequences through `_as_tuple_of` before validation. The file/store
readers always reach those constructors. Independent checks handed mutable lists directly to
each owner, verified tuple output and changed the input afterward: all **4 passed**. Restoring
the removed file conversion and the removed store conversion separately left those checks and
both persistence round trips passing (**6 passed** each). Removing the redundant conversions
therefore removes no validation or alias protection; it is not an untested survivor.
