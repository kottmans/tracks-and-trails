### Verified measurements

- Both inventory tests pass against the installed pin. The first derives the uncovered
  suppressed surface from the parser and pins its spellings; the second checks documented
  parser options against audit rows. The constant holds **39 spellings for 36 option objects**,
  consistent with the task's count. These are inventory guards, not yet the eventual complete
  admission-policy test.
- Re-running the survey reproduced **292 options; 175 changing keys, 72 with no dictionary
  difference, 45 unsuccessful sample parses, 27 changing multiple keys**. These describe the
  tool's selected sample values, not every possible value or combination. The geo-bypass
  counterexample is real; admission cannot rely solely on the diff.
- All **8 reservation tests passed**. They exercise a real loopback HTTP download onto an
  exclusive-create zero-byte target. A temporary pytest plugin removing `overwrites` from
  the options returned by `build_options` produced **4 failures / 4 passes**, with no setup
  errors: baseline, `--continue`, `--part`, and `--post-overwrites` failed on zero-byte output.
  Repository source was not edited for the mutation. The baseline passing run precedes it.
- This supports Finding 7's bounded question: each of the five individual settings preserves
  a complete direct download with `overwrites=True`. It does not establish all combinations,
  postprocessor behavior, resume from an existing partial, or a future parser/merge path.
