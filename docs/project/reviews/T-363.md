The expected missing-ffmpeg refusal is identical in both runs. Every probe
restores the original globals in `finally`; no executable or media was written.

The reviewer also instantiated the real `OptionsDialog` offscreen with the

### Classification and bundle judgment

The reviewer accepts the explicit-selection rule as a faithful reading of the
requested command-line contract. A meaningful bundle is itself the user's
selection and retains its yt-dlp members; an inert member carried by that bundle
is not a separate request for an unavailable capability. Direct positive inert
selections and intrinsically empty bundles receive the stated refusal. Deliberate
whole-line cancellations were already required by the original finding. Safety,
application ownership and control ownership still inspect the final expanded
set regardless of how a value arrived, so this rule opens no unsafe bundle route.
This resolves the no-effect admission finding rather than accepting it as risk.

The audit edits are necessary generator input for this correction. Their
classification was reviewed against the pinned library's actual reads and the
application's reachable paths. The Planner ownership header remains unchanged;
no requirement, accepted decision or runtime dependency is changed by this batch.

The twelve inert reasons were checked: three names have no runtime read at the
pin; error handling treats explicit false as the application's absent default;
format selection is always supplied; the listing path is unused; the playlist
reordering and CLI-only processor companions are refused or handled by the
application. The optional-package cases hold in the verified environment:
certifi, mutagen, requests and curl_cffi are absent, with Urllib the only handler.
Their absence tests appropriately require reclassification if that changes.
The two runtime-only positive controls show different rendered names and metadata
arguments under the application's real options, rather than just dictionary
membership. No claim is made for unknown future library/package combinations.

An independent public-boundary matrix passes **12** direct inert refusals,
**24** atomic cancellation forms, **14** admitted effective values, **5** meaningful
bundle selections and **7** empty/unsafe/owned refusals. Each effective value
produces a nonempty hatch. Removing only `_named_and_inert` in memory leaves the
test matrix's classifications intact and causes **13 regression failures**,
0.18 s, including the empty bundle; no cases silently disappear from collection.
