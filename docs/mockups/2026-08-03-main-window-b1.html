B1, three ways — and a recommendation

Settled: tabs, no detail pane, a comfortable row, every applicable verb visible without hovering, the format control only while it can still change, and no per-job pause. What is left is where the buttons sit — which is B1's one weak spot, because the number of verbs changes with the row's state and the gutter changes width with it.

B1-a · icon gutter, fixed width

Same verbs, drawn as icons. The gutter is one width for every state, so the titles line up down the list.

The decision

B1-b — the verbs share the format line. It is the only one of the three that costs nothing: same row height, full width for the title, and the failed row can show the extractor's message in full, which NFR-006 requires and the other two narrow. The buttons shifting position between states is a real cost and the smaller one — they are always at the right end of a line the eye is already on, and they are words rather than glyphs.

If the shifting bothers you in practice, B1-c is the fallback and needs no redesign: reserve the gutter, move secondary verbs into ⋯. B1-a I would not take — icons for Retry and Remove sitting next to each other is a mistake waiting to happen, and no tooltip prevents it.

What this settles, if you agree

  • Queue and History are tabs; there is no detail pane; rows carry everything.
  • Every applicable verb is visible on the row's last line, with ⋯ for the rest. Nothing is drawn disabled and nothing is drawn that would be refused.
  • The format control appears only while retarget() would accept it — queued and waiting rows, plain text once running.
  • There is no per-job pause. Pause queue is a toolbar verb; the status bar says what pausing actually does; a waiting row reads Held, never Paused.
  • History rows are the same rows, and removal is selection-scoped with files are never deleted carried in the status bar.

One thing I have flipped once and want confirmed: a finished download stays in the Queue tab, with Open and Show in folder, until Clear finished moves it on. It is drawn that way above. The alternative — leaving for History the moment it completes — is defensible, and it means the tab you are looking at stops answering "did it work".
